AI终身合伙人 长安八业

项目说明  2026年10月2日  发起人 秦斌

项目定位

长安八业面向西安八类行业中的资料整理、字段核对、业务草稿和任务交接，把重复工作写成可检查的 Skills 工作规格，再由岗位 Agent 按流程协作。项目为行业使用者提供直观入口，也为开发者保留输入、产物与验收依据。

当前版本已有沉浸式展示网站、1066项技能规划清单和8条可运行文件流程。清单中的64个岗位 Agent、24条协作流程及16条 Harness 规则仍为规划规格，尚未接通真实企业调度和消息渠道。

Skills Agent 与执行规则

Skills 说明一项工作怎样完成；Agent 负责一组岗位工作；协作流程规定先后依赖与交接；Harness 约束输入权限、结果检查、异常处理和留档。四者通过编号关联，读者可在网页或Excel中追查。

组成 | 规模与职责

Skills | 1066项任务规格，写明输入、步骤、产物、验收和失败处理。

岗位 Agent | 64个规划角色，每业8个；定义职责、并发、超时和人工复核人。

协作流程 | 24条规划流程，每业3条；明确依赖、可并行步骤与交接产物。

Harness | 16条规划规则；包括授权、最小权限、版本、去重、审计与恢复。

黑灯办公室的建议工作日

黑灯办公室设想让已授权、可验收的日常任务按班次处理，由人员接收异常与审核产物。以下采用政务便民清单中的工作日建议排班，北京时间；当前未启用自动调度。

时间 | 工作及产物 | 建议交接时间

09:30-09:40 | 核验指南版本，生成事项指南版本表 | 09:50

09:50-10:00 | 按办理情形核对必需与可选材料 | 10:10

10:10-10:20 | 整理提交、受理、结果领取步骤卡 | 10:30

17:10 | 汇总缺件、待签核和在办事项 | 当日日结

上述产物交政务服务业务专员审核，业务主管接收交接与异常。规划渠道为政务内网工作台待审核队列，真实名单和连接器尚待绑定。输入未到齐时生成缺项单；错过班次后进入待处理队列，由负责人确认是否补跑。

怎样量化验收

以事项指南版本表为例：生效状态准确率目标为100%，至少核对20个版本；未经授权执行次数目标为0，至少验证10次；验收后进入待审核队列的延迟目标不超过15分钟，至少记录10次完整链路。

准确率按与权威来源一致的记录数除以抽检记录数计算；日志保存输入版本、人工参照、差异和时间戳。阈值属于建议试运行标准，当前实测值为空。未达标先修正规则并复测，人工审核通过后才可按授权范围交付。



已实现的文件处理能力

8条现有流程支持合成示例、CSV或JSON输入与上传、异步执行、下载产物、人工确认或退回、取消、重试和运行留档。流程以文件计算和规则模板生成草稿，可选外部模型调用默认关闭。

2026年10月1日记录的8条主流程实际运行共处理24条合成输入，生成36份文件、20项待办，完成56个步骤；结果全部等待人工复核。此记录说明文件流程可执行，不代表客户落地成效、模型推理效果或1066项技能已运行。

公开案例与项目证据

16页路演材料将公开行业案例与本项目运行示例分开呈现。公开案例用于解释业务场景和技术方向，并非本项目客户；宣传场景图是概念配图。西安产业数据来自2025年统计公报，不能将八类应用领域当成互斥的GDP统计分类。

可追溯材料包括技能目录及其来源编号、样本输入与产物校验值、逐步运行记录。量化指标要在企业真实授权数据上重新校准，完成业务人员签认后，才可报告效果或节省的工时。

技术结构与本地启动

前端采用React、TypeScript与Vite，包含3D行业轮播、Three.js场景桥接和双图光圈揭层；Skills目录以JSON加载。Python后端处理文件流程，SQLite保存运行记录，产物写入本地目录。小店经营页面使用retail路由，后端保留finance标识。

安装仓库依赖后，在项目根目录打开两个终端：先执行 npm run server，后执行 npm run dev；浏览器访问 http://127.0.0.1:5192/ 。前端把 /api 请求代理到本机8771端口。后端默认数据目录为 server/data，实际业务数据应独立管理。

检查命令为 npm run lint、npm run typecheck、npm test、npm run test:experience 与 npm run build。补充组件检查可执行 node --test tests/lithos-library.test.mjs。

后续接入与开源协作

后续按一个真实岗位启动试点：确认资料和负责人，绑定数据源与接收渠道，用保留样本校准指标，再逐步启用任务排班。发布、付款、审批和设备控制等动作应独立授权。源码共享后，可围绕行业任务规格、连接器、测试样本和复核标准协作；公开仓库不应包含密钥、真实业务数据或未获许可素材。
